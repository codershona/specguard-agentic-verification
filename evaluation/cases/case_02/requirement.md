# Password Validation Requirements

1. Password length must be between 8 and 16 characters inclusive.
2. Password must contain at least one uppercase ASCII letter.
3. Password must contain at least one lowercase ASCII letter.
4. Password must contain at least one digit.
5. Password must contain at least one special character from !@#$%.
6. Password must not contain spaces.
7. Return VALID when all requirements are satisfied.
8. Return INVALID_PASSWORD when any requirement is violated.

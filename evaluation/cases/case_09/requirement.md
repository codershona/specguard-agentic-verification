# Coupon Validation Requirements

1. Coupon code must be a string.
2. Coupon code must contain exactly 8 characters.
3. Coupon code must contain only uppercase ASCII letters and digits.
4. Coupon code must start with the prefix SAVE.
5. Coupon code comparison must be case-sensitive.
6. Return VALID_COUPON when all requirements are satisfied.
7. Return INVALID_COUPON when any requirement is violated.

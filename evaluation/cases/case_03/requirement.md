# Email Validation Requirements

1. Email must contain exactly one @ character.
2. Email must contain at least one character before @.
3. Email must contain at least one character after @.
4. The domain part must contain at least one dot.
5. Email must not contain spaces.
6. Email must contain only ASCII characters.
7. Return VALID when all requirements are satisfied.
8. Return INVALID_EMAIL when any requirement is violated.
